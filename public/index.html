Audio Analysis

          
Settings that control waveform analysis quality and section detection. Changes apply to new analyses only — re-analyze tracks to see the effect.


          

            
              

                Setting
                Value
              

            
            
              

                
                  Waveform Resolution
                  
Number of peak points in the waveform overview. Higher = more detail but larger data. Default: 2000

                		
                
                  
                
              

              

                
                  Analysis Sample Rate
                  
Sample rate for PCM decoding. Higher captures more detail but uses more CPU. Default: 22050 Hz

                		
                
                  
                
              

              

                
                  Section Sensitivity
                  
How aggressively section boundaries are detected. Lower = more sections, higher = fewer larger sections. Default: 1.2

                		
                
                  
                
              

              

                
                  Amplitude Normalisation
                  
Percentile used for waveform normalisation. 99% avoids transient spikes squashing the display. 100% = strict max. Default: 99

                		
                
                  
                
              

            
          


          

            
🛈 Analysis settings only affect new analyses. To apply changes to previously-analyzed tracks, re-analyze them from the sequencer library.
