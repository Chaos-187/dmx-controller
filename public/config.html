🎤 Audio Input

Configure a live audio source for sound-reactive lighting effects (Sound Pulse, Sound Strobe, Sound Chase, etc.). The server captures audio in real-time via ffmpeg and computes bass, mid, and treble energy levels. When enabled this takes priority over track-analysis data.

🌧 ASIO & Outgoing Audio

ASIO devices — ffmpeg has no native ASIO driver, but every ASIO interface also installs a WDM driver that appears in the scan as a regular device (e.g. "Line (Focusrite USB)", "Line (MG-XU)"). Select OpenAL format for the most complete device list. If your interface still doesn't appear, install FlexASIO or route through VoiceMeeter to bridge ASIO → WDM.

Outgoing / system audio (Windows) — Enable Stereo Mix in Windows Sound settings:

  1. Right-click the speaker icon in the system tray → Sounds
  2. Open the Recording tab → right-click in the list → tick Show Disabled Devices
  3. Enable Stereo Mix (or Wave Out Mix / What U Hear)
  4. Select OpenAL format above and click Scan — Stereo Mix will appear

macOS: use BlackHole or Loopback · Linux: PulseAudio exposes a .monitor source for every output sink automatically.
